## Overview

**Drishtikon** is a UI prototype for an **Explainable AI-based Diabetic Retinopathy (DR) Screening Platform** designed as a clinical decision-support system.

The interface is designed around real-world healthcare challenges such as **poor retinal image quality, uncertain AI predictions, limited connectivity, and patient language barriers**.

The prototype demonstrates how a complete screening ecosystem could work through dedicated **Doctor and Patient portals**, bringing AI-assisted analysis, explainable results, human verification, reporting, and multilingual accessibility into one platform.

> **Note:** This repository currently focuses on the **UI/UX prototype and product workflow**. The AI predictions, Grad-CAM analysis, confidence scores, and other intelligent features shown in the interface are represented as prototype/simulated functionality.

## Key Features

### Doctor Portal

- Patient management and screening workflow
- Retinal image / video upload
- Image quality assessment interface
- AI-based DR screening results
- Severity classification
- Confidence / uncertainty indicators
- Explainable AI heatmap visualization
- Clinician verification
- Structured medical report review

### Patient Portal

- Mobile-friendly results interface
- Easy-to-understand screening information
- Simplified medical explanations
- Multilingual interaction
- Voice-based assistance concept using Speech-to-Text and Text-to-Speech

## Design Focus

Drishtikon's interface focuses on creating a healthcare experience that is:

- **Clinician-focused** — clear information for faster review
- **Explainable** — visual representation of AI findings
- **Accessible** — simplified patient-facing information
- **Multilingual** — designed for regional-language support
- **Human-in-the-loop** — automated findings remain subject to clinical verification
- **Real-world oriented** — designed with low-quality images and connectivity challenges in mind

---

## Current Status

**Drishtikon is currently a UI/UX prototype.**

The project demonstrates the visual design and workflow of the proposed platform, including the doctor dashboard, patient experience, screening results, explainability views, verification flow, and reporting interface.

The next stage of development would involve integrating trained retinal-image models, real Grad-CAM analysis, uncertainty estimation, multilingual AI services, secure backend infrastructure, and clinically validated workflows.
